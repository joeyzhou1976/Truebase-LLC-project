# TrueBase 产品图片素材

本目录由 `generate_truebase_product_image_assets.js` 从用户提供的 14 张棚拍图生成。

- `source/`: 原始图片副本。
- `product-line/`: 产品页面产品线替换图，尺寸 1920x1080，带背景画面、TrueBase 品牌标识和产品线文案。
- `spec-white/`: 具体产品规格页白底图，尺寸 1600x1200，适合商品详情、规格表和询盘页面。
- `manifest.json`: 每张源图、产品线图、白底图的路径映射。

Canva 可编辑模板：

- Keepsake Boxes 代表模板: https://www.canva.com/d/CF6uRxG1XfzpOJV

建议用法：

- 产品总览/产品线模块：优先使用 `product-line/` 下的图片。
- 单品规格/详情模块：优先使用 `spec-white/` 下的同名图片。
- 如果需要在 Canva 里继续调整字体、标题或背景，可用上面的模板作为样式参考，再逐张导入同目录成品图。
